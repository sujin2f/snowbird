# Snowbird

Snowbird is a WordPress **block theme** (FSE) built with `@wordpress/scripts` and SCSS. It ships a
set of custom block patterns, template parts, and styles, and follows the WordPress VIP coding
standards for PHP.

- **Theme URI:** https://Snowbirdlms.com
- **Requires at least:** WordPress 6.4
- **Requires PHP:** 8.0+
- **License:** GPL-2.0-or-later

## Requirements

| Tool     | Version |
| -------- | ------- |
| PHP      | >= 8.0  |
| WordPress | 6.4+   |
| Node.js  | 18+ (recommended 20+) |
| Yarn     | 1.x    |
| Composer | 2.x    |
| Docker   | optional, for local development |

## Getting started

```bash
# 1. Install JS dependencies
yarn install

# 2. Install PHP dev dependencies (PHP_CodeSniffer + standards)
composer install

# 3. Build the theme assets into /build
yarn build
```

### Local development with Docker

A ready-to-use WordPress setup is included:

```bash
docker compose up -d
```

WordPress runs at <http://localhost:8080> and the theme is mounted at
`wp-content/themes/snowbird`. MySQL credentials are defined in `docker-compose.yml`
(`exampleuser` / `examplepass` / `exampledb`).

## Development commands

### JavaScript / CSS

```bash
yarn start        # watch and rebuild assets on change
yarn build        # production build into /build
yarn format       # format JS/CSS with Prettier
yarn lint:js      # ESLint
yarn lint:css     # Stylelint
yarn lint:pkg-json
yarn check-engines
yarn check-licenses
```

### PHP

```bash
yarn lint:php        # runs vendor/bin/phpcs
yarn lint:php:fix    # runs vendor/bin/phpcbf

# or directly with Composer
composer lint:php
composer lint:php:fix
```

## Project structure

```
.
├── build/              # Compiled assets (generated by wp-scripts)
├── docs/               # Operational docs (caching, SSL)
├── parts/              # Template parts (header, footer, icon parts)
├── patterns/           # Block patterns (about, contact, hero, services)
├── src/
│   ├── images/         # Source images (logo, favicons, hero/profile defaults)
│   ├── styles/
│   │   ├── blocks/     # Styles per custom block
│   │   ├── parts/      # Styles for header/footer
│   │   ├── patterns/   # Styles for block patterns
│   │   ├── index.scss  # Entry point aggregator
│   │   └── mixins.scss
│   └── index.ts        # Webpack entry (imports styles)
├── templates/          # Block templates (front-page, index)
├── functions.php       # Theme setup, asset enqueue, optimizations
├── theme.json          # Editor settings: palette, font sizes, custom props
├── webpack.config.js   # Extends the default wp-scripts config
├── .phpcs.xml.dist     # PHP_CodeSniffer ruleset (VIP Go + WP Extra/Docs)
└── docker-compose.yml  # Local WordPress + MySQL
```

## Coding standards

PHP follows the **WordPress VIP Go** ruleset, plus `WordPress-Extra`, `WordPress-Docs`, and
PHP cross-version compatibility checks for PHP 8.0+. Globals/functions must be prefixed with
`snowbird`, and the text domain must match the theme slug. Configuration lives in
`.phpcs.xml.dist`.
